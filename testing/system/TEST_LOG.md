# System — test log

End-to-end verification of the complete **Team CSC03** autonomous rover against all functional (`FR1`–`FR12`) and non-functional (`NFR1`–`NFR10`, `NFR12`) requirements. Run the full hardware set on the final assembled course setup before every demo and hand-in.

See `testing/README.md` for how to run tests and record results.

## Test cases
